StarExec Helm Charts

Official Helm repository for the StarExec Logic Solver Competition Platform

Add the repository:

helm repo add starexec https://starexecmiami.github.io/StarExec
helm repo update

Search for charts:

helm search repo starexec

Install StarExec:

# Install latest version
helm install starexec starexec/starexec --create-namespace -n starexec

# Or install specific version
helm install starexec starexec/starexec --version 0.1.0 -n starexec

Customize installation:

# With your own values file
helm install starexec starexec/starexec -f my-values.yaml -n starexec

# View available configuration options
helm show values starexec/starexec
