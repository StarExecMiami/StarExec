# Contributing to StarExec

Thanks for considering contributing! This file contains minimal guidelines to
get started. For larger changes, please open an issue first to discuss the
approach.

## How to contribute

1. Fork the repository and create a feature branch for your work.
2. Keep changes focused and add tests where applicable.
3. Run existing checks (build, tests) before opening a pull request.
4. Open a pull request describing the change and why it is needed.

## Code style

- Follow the existing repository conventions.
- Add Java unit tests for logic changes and minimal integration tests where
  possible.

## Reporting bugs and feature requests

Use the GitHub issue tracker: [Issues](https://github.com/StarExecMiami/StarExec/issues)

- Provide logs, steps to reproduce, and environment details where possible.

## Security issues

If you discover a security vulnerability, please do not open a public issue.
Contact the maintainers privately via email listed on the project page or via
GitHub security advisories.
